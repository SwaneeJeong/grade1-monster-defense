# 🔢 초1~초6 수학·낱말 디펜스

초등학교 1~6학년을 위한 **수학 · 한글 낱말 디펜스** 게임입니다.
옛날 타자 게임처럼 몬스터가 다가오기 전에 문제를 풀어서 물리치는 방식이에요.

## 놀이 방법

| 모드 | 내용 |
| --- | --- |
| 🔢 수학 대모험 | 고른 학년의 수학 문제 3단계 |
| 🔤 한글 낱말 탐험 | 그림 보고 낱말 맞히기 + 빈칸에 들어갈 글자 맞히기 |
| ⚡ 무한 혼합 | 수학 + 낱말이 함께 나오는 끝없는 모드 |

- 시작 화면에서 **학년(초1 ~ 초6)** 을 먼저 고릅니다. 고른 학년은 기억돼요.
- 스테이지마다 8마리를 물리치면 **보스 몬스터**가 나타납니다.
  - 1단계 👑 대왕 슬라임 · 2단계 🔥 불꽃 드래곤 · 3단계 👑 우주 대마왕
- 하트 ❤️ 5개를 모두 잃으면 게임이 끝나요.
- 최고 점수는 **모드 × 학년마다 따로** 기기에 저장됩니다.

## 학년별 수학 문제

| 학년 | 문제 |
| --- | --- |
| 초1 | 한 자리·두 자리 덧셈·뺄셈 (10 이하 → 20 이하 → 받아올림·내림) |
| 초2 | 곱셈 구구(2~9단), 두 자리 받아올림 덧셈·내림 뺄셈 |
| 초3 | 두 자리 × 한 자리, 나눗셈, 세 자리 덧셈·뺄셈 |
| 초4 | 두 자리 × 두 자리, 세 자리 × 한 자리, 두 자리 나눗셈, 혼합 계산(`3 + 4 × 5`) |
| 초5 | 괄호가 있는 계산(`(12 + 8) ÷ 4`), 최대공약수·최소공배수, 단위 바꾸기(`3시간 = ?분`) |
| 초6 | 퍼센트(`200의 30%`), 비율(`3 : 5 = 12 : ?`), □가 있는 식, 암산 도전(`25 × 16`) |

정답은 모두 0 이상의 정수라서 숫자판으로 그대로 입력할 수 있습니다.

## 주인공 사진 넣기 (선택)

시작 화면의 **📸 주인공 사진 넣기** 버튼으로 우리 아이 얼굴 사진을 주인공으로 넣을 수 있어요.

- 고른 사진은 **✂️ 얼굴 맞추기** 창이 열려서, 손가락으로 밀고 🔍 막대로 크기를 맞춰 얼굴을 타원 안에 딱 넣을 수 있어요. `이대로 적용!` 을 누르면 그 부분만 180×218 크기로 잘려서 **그 기기의 브라우저 저장 공간(localStorage)에만** 보관합니다. 어디로도 올라가지 않아요.
- 타원 가이드는 게임 속 주인공 얼굴(.hero-head)과 똑같은 56:68 비율이라, 자른 그대로 얼굴만 동그스름하게 오려 붙인 것처럼 보입니다.
- 게임을 시작하면 아래쪽 잔디 위에 **얼굴만 동그스름하게 오려 붙인 것 같은 주인공**이 붕 떠 있고(테두리·링·배지 없음), 옆에는 **작은 만화 장갑 손**이 뭉툭한 미사일을 들고 있습니다.
- 정답을 맞히면 **손에 들고 있던 미사일이 그 자리에서 몬스터를 향해 날아갑니다**(주인공은 푱! 하고 찌그러졌다 늘어나는 재미있는 반동, 장갑 손은 휘청, 다음 미사일이 다시 장전됩니다).
- **초기화** 를 누르면 기본 로켓 주인공으로 돌아갑니다. 사진을 바꾸는 것도 시작 화면에서 언제든 할 수 있어요.

## 조작

- **수학** : 화면 숫자판을 누르거나, 키보드 숫자 + `Enter`(발사). `⌫` 는 지우기.
- **낱말** : 화면 보기 버튼을 누르거나 키보드 `1` `2` `3` `4`.
- 다른 몬스터를 눌러 공격 대상을 바꿀 수 있어요. (`🎯`)
- `⏸` 일시정지, `🔊` 소리 켜기/끄기.
