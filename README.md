# 🔢 초1 수학·낱말 디펜스

초등학교 1학년을 위한 **수학 · 한글 낱말 디펜스** 게임입니다.
옛날 타자 게임처럼 몬스터가 다가오기 전에 문제를 풀어서 물리치는 방식이에요.

## 놀이 방법

| 모드 | 내용 |
| --- | --- |
| 🔢 수학 대모험 | 1학년 더하기·빼기 3단계 (10 이하 → 20 이하 → 받아올림·내림) |
| 🔤 한글 낱말 탐험 | 그림 보고 낱말 맞히기 + 빈칸에 들어갈 글자 맞히기 |
| ⚡ 무한 혼합 | 수학 + 낱말이 함께 나오는 끝없는 모드 |

- 스테이지마다 8마리를 물리치면 **보스 몬스터**가 나타납니다.
  - 1단계 👑 대왕 슬라임 · 2단계 🔥 불꽃 드래곤 · 3단계 👑 우주 대마왕
- 하트 ❤️ 5개를 모두 잃으면 게임이 끝나요. 최고 점수는 기기에 저장됩니다.

## 조작

- **수학** : 화면 숫자판을 누르거나, 키보드 숫자 + `Enter`(발사). `⌫` 는 지우기.
- **낱말** : 화면 보기 버튼을 누르거나 키보드 `1` `2` `3` `4`.
- 다른 몬스터를 눌러 공격 대상을 바꿀 수 있어요. (`🎯`)
- `⏸` 일시정지, `🔊` 소리 켜기/끄기.

## 실행

`index.html` 한 파일로 되어 있어서 인터넷 없이도 그대로 열 수 있습니다.
휴대폰(아이폰/아이패드)과 PC 모두에서 화면에 꼭 맞게 나옵니다.
